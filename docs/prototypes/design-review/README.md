# Design Review Prototype

This folder contains a PC-friendly clickable mockup for reviewing the current v0.3 UX/UI direction without Xcode.

Open `index.html` in a browser and review:

- Today screen hierarchy.
- Photo-first daily entry flow.
- Private people tagging and Memories filters.
- Optional Little Details for phases, favorites, routines, and milestones, including per-detail people tags.
- Three nice things input.
- Memory Lane tone.
- Memories, Calendar, Insights, and Settings tab structure.
- Warm palette and overall emotional tone.

This prototype mirrors the SwiftUI direction, but it is not production app code. Use it for taste calibration and UX feedback before the next SwiftUI implementation pass.
